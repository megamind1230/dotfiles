#+TITLE: dt's dotfiles

Personal configuration for an Arch Linux setup: dual Wayland (Hyprland) / X11 (i3) sessions, bash, Emacs, two Neovim configs, Helix, Zed, Kitty, mpv, plus a toolbox of shell scripts.

The repo mirrors =$HOME=: files get symlinked into place (=~/.bashrc=, =~/.emacs=, =~/.config/*=). =~/scripts= is a symlink to this repo's =scripts/= directory and is added to =$PATH=, so every script here runs as a bare command from anywhere.

* Shell files
** =.profile=
*Why:* sourced by the display manager / login shell — sets the environment before Hyprland or i3 starts. Non-interactive counterpart of =.bashrc=.

Sections:
- *Exports* — =EDITOR=/=VISUAL==nvim=, =BROWSER=brave=, =TERMINAL=kitty=
- *PATH* — prepends =~/.opencode/bin=, =~/.local/bin=, =~/.config/emacs/bin= (doom), =~/.emacs.d/bin=, =~/scripts/= (the symlink into this repo), =~/.dotnet/tools=; appends =/opt/nvim-linux-x86_64/bin=

Note: uses =BROWSER=brave= while =.bashrc= uses =brave-browser= — a small inconsistency between the two files.

** =.bashrc=
*Why:* main bash config for interactive shells. It's an *orchestrator*: baseline settings, then sources the three extension files in order.

Sections:
1. *Interactivity guard* — returns immediately for non-interactive shells
2. *History* — no dupes / ignores space-prefixed commands, append mode, HISTSIZE=1000
3. *Shell options* — checkwinsize (globstar/lesspipe commented out)
4. *Environment* — opencode on PATH; =MANPAGER='nvim +Man!'= and =MANWIDTH=999= (man pages inside nvim); EDITOR/VISUAL/BROWSER(=brave-browser=)/TERMINAL; PATH prepends (.local/bin, emacs bins, scripts/, dotnet tools); recording defaults =SCREENREC_AUDIO_SINK= / =SCREENREC_AUDIO_SOURCE= consumed by the mic/screenrecording scripts
5. *Prompt* — color PS1 =user@host:cwd$=, sets xterm window title
6. *ls colors* — dircolors eval + basic =ls --color= alias (overridden later by -aliases)
7. *Completion* — sources bash-completion
8. *Source chain* — =.bashrc-personal= → =.bashrc-aliases= → =.bashrc-functions=; this order defines precedence

** =.bashrc-personal=
*Why:* the "survives a skel overwrite" personal layer, sourced first.

Sections:
1. *Prompt* — custom PS1: italic-yellow =(10:42 AM)= time, then =user:host=, then bold-cyan =[cwd]=, then =$=
2. *Commented-out vi-mode experiment* — =set -o vi= + Ctrl-L clear binds (disabled)
3. *Startup word* — if =/mnt/hdd/words.txt= exists and is non-empty, prints one random line (magenta) at each new shell — pairs with the =new-word= script and =nw= edit alias

** =.bashrc-functions=
*Why:* functions, fzf integrations, readline keybindings, and the competitive-programming generator. Sourced last. Uses =# @desc= comments above definitions — parsed by the Alt+F picker as documentation.

Sections:

*** Package management
- =inst <pkgs>= sudo pacman -S; =pinst= paru (AUR); =search= / =psearch= query results printed bottom-up (=tac=)

*** Archives
- =ex <archive>= extracts by extension (tar, tar.gz/tgz, tar.bz2, tar.xz, zip, rar, 7z, gz, bz2)
- =compress <out> <src>= creates tar/tar.gz/tar.bz2/tar.xz/zip/7z by output extension

*** Neovim config switcher
- aliases =nvimlazy= / =lz= run =NVIM_APPNAME=LazyVim nvim=
- =nvims= fzf menu choosing =nvim= (default config) vs =LazyVim=, then execs with the right =NVIM_APPNAME=
- *Alt+N* readline bind invokes =nvims= directly from the prompt

*** Script runner
- =scriptsRun= lists executable files in =~/scripts= with their first =# @desc= line, fzf-picks one, runs it
- *Alt+S* readline bind invokes it from the prompt

*** Fuzzy search family
Shared recipe: live ripgrep re-run as you type (fzf =change:reload=), bat preview highlighting the match, right pane.
- =rgnv= content search in cwd → Enter opens =nvim +<line> <file>=
- =rgnvp= same but pick the search directory first via fd
- =rgy= pick directory, search it, open the matched file's parent in yazi
- =rgcopy= copies =file:line= of the pick to the clipboard (wl-copy/xclip)
- =fzy= fuzzy-pick a dir under $HOME → yazi
- =fmv= pick source file, pick destination dir, move
- =fdoc= browse md/org/txt notes in =/mnt/hdd/obsi/vault_bank= with preview → nvim
- =fcd= fuzzy cd over all directories (junk excluded)
- =fcdg= fuzzy cd restricted to git repositories under =/home/dt=

*** Tmux workspace
- =bakam= creates detached session =baka=: window 0 =extra=, 1 =doc= (nvim /mnt/hdd/doc), 2 =grep= (vault), 3 =notes= (Desktop/new.md), 4 =quotes= (my-quotes.txt) — then attaches. Reattach anytime with =bakat=

*** Utilities
- =path= $PATH one per line; =pubip= public IP; =ports= listening ports; =up [N]= go up N dirs
- =print_random_quote= random line from my-quotes.txt
- =crondo= interactive random-file organizer loop for =/mnt/hdd/hcore= (y → Downloads, else → hcoreExtend, q quits)

*** Competitive programming (cps system)
Naming convention: =<website><language><ide>=.
- =cps cf|lt <lang> n|e|h|v|z= prompts for problem link/number, derives an id, clones the language template from =~/cp/templates/= into =~/cp/<site>-<id>-.../=, renames csproj for C#, opens the IDE:
  - =n= LazyVim + competition.lua layout; =e= emacsclient (loads =dt-cp-open.el=); =h= helix; =v= code; =z= zed
- Generates *60 wrapper functions* covering the full matrix (cfcsc…ltrsgz) so each combination is one command
- Note: =cps e= references =$HOME/dotfiles/dt-cp-open.el=, which is not present in this repo

*** Readline fuzzy pickers
- *Alt+A* =fuzzy_alias= → insert picked alias name at prompt
- *Alt+F* =fuzzy_function= → parses =# @desc= blocks, inserts picked function name at prompt

*** fzf integration
- final line evals =fzf --bash= → stock Ctrl-T / Ctrl-R / Alt-C bindings (loaded after the custom functions on purpose)

*Why:* hyprpaper's wallpaper pointer. Just one =wallpaper {}= block (monitor=all, fit=cover). Its =path= is regenerated by wallpaper.sh at every boot.

*Why:* random-wallpaper daemon started by autostart. Picks a random jpg/png from =/mnt/hdd/Favorites=, rewrites hyprpaper.conf with it, kills and re-execs hyprpaper.

* Scripts (=scripts/= — all on =$PATH= via =~/scripts= symlink)

Most scripts start with a =# @desc= line; that metadata is what the Alt+S runner and Alt+F picker display.

Architecture of the recording suite:

#+BEGIN_SRC
            record  (launcher: screen [+ audio] + mic → merged mp4)
           /   |    \
  screenrecord | screenrecord-audio     mic
               \ |                 (9-stage ffmpeg chain)
          p_lib_session.sh  (display/compositor/audio/clipboard abstraction)
#+END_SRC

** =p_lib_session.sh=
*Why:* POSIX-sh library sourced by recording scripts so they work unchanged on Wayland and X11.
Functions: =detect_display_server= (wayland/x11), =detect_compositor= (hyprland/sway/i3/…), =get_monitor_dimensions= (hyprctl/swaymsg/xdotool, fallback 1920x1080), =get_window_dimensions=, =get_recordings_dir= (=$SCREENCAST_DIR= or =~/Videos/Screencast=), =get_audio_sink_monitor= / =get_audio_source= (env override or pactl default), =copy_to_clipboard= (wl-copy / xclip / xsel).

** =record=
*Why:* one command → final mp4 with screen + microphone.
Flow: menu (1 = screen only, 2 = screen + desktop audio) → generates temp wrapper scripts that force sub-scripts to write shared filenames → starts video recorder + =mic= in parallel → Ctrl+C stops both (INT trap forwards signals) → sanity-checks outputs → merges: mode 1 stream-copies mic track under video; mode 2 amerge-mixes desktop audio + mic 50/50 → cleans up temps, prints final path.

** =screenrecord=
*Why:* silent screen-only capture. hyprland → wl-screenrec; sway/wayland → wf-recorder; i3/x11 → ffmpeg x11grab lossless ultrafast. Caveat: does not source p_lib_session.sh itself, so standalone use depends on running through =record='s wrappers (see Notes).

** =screenrecord-audio=
*Why:* screen + *desktop* audio. Sources the library, resolves the sink monitor, then wl-screenrec --audio / wf-recorder -a / ffmpeg pulse+grab. No mic — use =record= for that.

** =mic=
*Why:* studio-grade voice recorder to AAC .m4a. Nine individually-commented filter stages: mono→stereo pan, 100Hz highpass + 16kHz lowpass, FFT noise reduction (nr=12), adeclick, deesser, firequalizer voice EQ curve, compand (downward expansion + soft-knee compression), +2dB gain, true-peak limiter at −2dB.

** =pdfdash=
*Why:* entire PDF toolkit behind one fzf menu. Deps: pdftk, poppler-utils, fzf, ghostscript.
Menu: Extract Images (png/jpeg/tiff, all/custom pages) / Extract PDF Pages ("1-3 5 8") / Merge PDFs (multi-select) / Compress (screen/ebook/printer/prepress presets) / Encrypt (owner+optional user pw) / Decrypt / Rotate (90cw/ccw/180). Every op opens an fzf PDF picker previewing path, size, page count and first lines of text. Known bugs tracked in =scripts/bugs.org= (e.g. Ctrl+D at password prompt exits due to =set -e=).

** =file-organizer=
*Why:* sort a messy folder. Category map for imgs/docs/aud/vid/archives/installers (+others). Interactive menu (1 container by index list, 2 keyword patterns w/ optional regex, 3 auto-category-sort, l list, r reverse/flatten, q quit) or CLI flags: =--source --patterns --container --dry-run --reverse --one-shot --regex --interactive=. Collision-safe names (name(1).ext), logs to =logs/app-YYYYMMDD.log=.

** =snapshot-rofi=
*Why:* GTD-style quick capture into org-mode. Opens rofi pre-filled with existing inbox notes (newest first); picking existing text jumps nvim to that exact line; new text appends a heading block to =~/org/inbox.org= and — if the clipboard holds an image (cliphist/wl-paste/xclip detection chain) — saves it as =imgs/DD-MM-YYYY@hh-mm-ss-AM.png= and links it.

** =emote=
*Why:* emoji + kaomoji picker. Self-extracting file: code before =exit=, 3,380-entry data section after =### DATA ###=; pipes rofi selection through wl-copy (Wayland) or xclip (X11). Includes full country-flag set and combo families like =(⌐■_■)=.

** =calc=
*Why:* rofi calculator. Expression → =bc -l= (sqrt/trig/log available) → result copied to clipboard + notify-send "=expr = result=".

** =rofi-searchweb=
*Why:* search launcher. First rofi prompt takes the query, second picks engine (google/duckduckgo/brave/github/youtube/arch wiki/man.archlinux), URL-encodes via jq, opens with xdg-open.

** =new-word=
*Why:* vocabulary capture feeding the shell startup-word feature. Two rofi prompts (word, meaning/context) append =word | meaning= to =/mnt/hdd/words.txt= with a notification.

** =rand52=
*Why:* self-quiz generator. fd lists .txt files → fzf pick → shuf 52 lines → numbered list written to =./answers.txt=.

** =timer=
*Why:* countdown + time tracking. Prompts duration (termdown syntax: 30s, 5min, 1h30m…) and task name, runs termdown, plays timer-sound.mp3, appends =task/start/end/duration= row to =/mnt/hdd/tasks-log.txt=.

** =toglang=
*Why:* X11 layout toggle US ↔ Arabic via setxkbmap query/set. Bound to Super+Space in i3.

** =region-to-gif=
*Why:* region GIF recorder. Wayland: =wlgif -o ~/Pictures/out.gif=; else byzanz-record with xrectsel geometry. Ctrl+C stops.

** =cwp=
*Why:* interactive wallpaper chooser with chafa image previews over =/mnt/hdd/Favorites= (fd+fzf). Wayland: applies through hyprpaper to every connected monitor; X11: xwallpaper --focus.

** =tst=
*Why:* debug probe echoing which display server is active ($XDG_SESSION_TYPE, falling back to $WAYLAND_DISPLAY/$DISPLAY).
